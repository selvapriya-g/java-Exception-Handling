# Java Exception Handling

This repository contains Java programs created to practice and understand **Exception Handling** in Java.

## Concepts Covered

* `try-catch` block
* `finally` block
* `ArithmeticException`
* Multiple exception handling
* Checked exceptions
* Unchecked exceptions
* Exception handling using `throws`
* Common runtime exceptions

## Programs

| Program  | Concept                     |
| -------- | --------------------------- |
| Ex1.java | Basic Exception Handling    |
| Ex2.java | Arithmetic Exception        |
| Ex3.java | Finally Block               |
| Ex4.java | Multiple Exception Handling |

## Technologies Used

* Java
* Command Prompt
* JDK

## How to Run

Compile the program:

```bash
javac Ex1.java
```

Run the program:

```bash
java Ex1
```
